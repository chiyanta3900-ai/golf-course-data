# ゴルフ手帳 コースデータ

ゴルフ手帳向けの公開コースデータ。スコア、個人の位置情報、アカウント情報は含みません。

`catalog.json` の `schema` はデータ形式、`revision` は配信の通し番号です。更新時は全コースを含めて番号を増やします。アプリは起動時に取得・検証し、端末へ保存します。

配信番号5では、G-style18H、三日月18H、市川9実ホール（1/10～9/18）の45実ホール・54番号について、番号・開始側・経路・グリーンを資料と照合し直しました。公式PARとレギュラー距離も54番号すべて確認しています。資料上の照合であり、現地測量や現地GPS精度の検証ではありません。

市川は2020年度の国土地理院写真で芝面と砂面を区別し、9実ホールのグリーンを取り直しました。1Hの建物横断、3Hの池の反対側の開始参照、5～8Hなどの位置の誤りも修正しています。二周目の距離はOUTの複製をやめ、公式INの距離を個別登録しました。公式ギャラリーには汎用写真が含まれるため、番号の照合には使用していません。

三日月は配信番号4の6H・18Hの修正に加え、7Hの池内の開始基準、15Hの通路側、16Hの道の反対側の開始基準を修正しました。PGM公式図と番号入り公開ドローン映像を国土地理院写真と比較し、根拠のない番号入れ替えは行っていません。

位置・輪郭は写真からの推定値です。カメラ用の開始基準はティー周辺を含めるための概略点であり、実測ティー位置として距離に使いません。表示範囲はフェアウェイ・池・OBの境界ではありません。

配信データは既存0.1.4以降で取得可能です。スマホの起動または「更新確認」で取得し、新しく始めるラウンドに適用します。既存ラウンドは開始時の版を保持します。市川の二周目は同じグリーンを使い、公式距離は別に保持します。個々のティーの実測位置は登録していません。

スマホ0.1.6では市川に2020年度の国土地理院写真を使い、未収録範囲は標準写真で補います。0.1.6は修正データも同梱し、通信できない起動でも修正済みデータを使えるようにしています。アプリの配布状況とコース配信は別です。

出典・確認日は各コースの `sources`・`retrieved` を参照してください。OSM由来の範囲とG-styleの形状にはODbL 1.0が適用されます。市川・三日月の推定位置は地理院タイルを加工して作成しています。出典：国土地理院。

公式コース図・ドローン映像・背景写真の画像は配信データに含めません。背景写真はアプリから国土地理院へ取得します。詳細は `DATA-LICENSE.txt` を参照してください。
