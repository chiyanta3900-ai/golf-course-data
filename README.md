# ゴルフ手帳 コースデータ

ゴルフ手帳向けの公開コースデータ。スコア、個人の位置情報、アカウント情報は含みません。

`catalog.json` の `schema` はデータ形式、`revision` は配信の通し番号です。更新時は全コースを含め、番号を増やします。アプリは読み取り専用で起動時に確認し、検証後に端末へ保存します。取得できない場合は保存済みデータを使います。

配信番号4では、三日月6Hの開始基準が11Hティー側にあり道路を越える経路になっていた問題を修正。18Hも隣接ホール側からではなく東端の南側のティー領域から表示するよう修正しました。7/11/15/16Hの開始側・経路、G-styleの11/18Hの表示基準も見直しました。

前回の輪郭修正と画像の読込確認だけでは、ホールの開始側・経路が正しいことを確認できていませんでした。三日月は楽天GORAの番号入り公開ドローン映像、PGM公式ホール図、地理院航空写真で再照合しています。写真上の概略位置であり、現地精度や全ティーの実測位置を保証するものではありません。

G-style、市川ゴルフ、三日月カントリークラブのホール別表示に対応しています。市川は9つの実ホールを1/10～9/18として二周、三日月は18ホールです。公式の番号・距離表と地理院航空写真を照合しています。位置・輪郭・表示範囲は推定値で、測量値ではありません。写真のぼけ・影による不確かさがあり、現地精度は未確認です。表示範囲はフェアウェイやOBの境界を示しません。

スマホ・ウォッチの0.1.4が必要です。スマホの次の起動または「更新確認」で取得し、新しく始めるラウンドに適用します。既に開始したラウンドは開始時のコース情報を保持します。市川の二周目も同じグリーン位置を使います。ティー位置・距離の違いは未登録です。

スマホ0.1.5では、航空写真をそのまま表示し、タップ・ドラッグした目標点までの距離を確認する画面へ変更します。画面変更にはアプリ更新が必要です。コース配信の更新とアプリの配布状態は別です。

各コースの出典・確認日はデータ内の `sources`・`retrieved` を参照してください。OpenStreetMap由来の範囲・G-styleの形状にはODbL 1.0が適用されます。市川・三日月の位置・概略形状は地理院タイル（空中写真）を加工して作成。出典：国土地理院。詳細は `DATA-LICENSE.txt` を参照してください。公式コース図・航空写真の画像は含みません。
